# Faber v1.9.1

## 修正与改进

- Runtime 网络令牌和 OAuth 密码恢复默认隐藏及眼睛按钮；插件中的地址、参数和手填密钥继续明文展示，两处共用表单、输入框和清除按钮样式。
- 外部 MCP 意外断开后立即撤销该服务的工具，并按 1、2、4、8、16 秒间隔尝试重连，最多 5 次；提供“重新连接”入口，无需重启整个 Runtime。停止 Runtime 会取消重试，内置 Computer Use 不自动重启，未完成的工具调用不会自动重放。
- stdio 单条响应上限由原来的 4 MiB 调整为 SDK 默认的 10 MiB；超限响应、无效 stdout、程序缺失以及子进程退出码/信号现在有明确诊断，便于排查大型 Figma 数据返回和子进程异常。

## 验证与升级

- 类型检查、Vue 类型检查、前端构建、服务打包和包边界检查通过；43 项相关回归及 8 项新增断线/大响应测试通过。
- 浏览器使用隔离夹具验证 Runtime 显隐、插件明文回显、共同组件样式、保存与草稿测试，以及手动重连入口。测试和记录仅保存在本地。
- Framelink 原始断链原因尚需新的退出日志确认，本次改善连接恢复与诊断，不将未知原因认定为已查明；未调用真实 Figma 业务工具。
- 安装更新后重新启动 Runtime。三平台安装包及签名更新由版本标签 CI 生成、校验并发布。
