# Faber v1.10.1

## 功能更新

- 更新 Computer Use，改善桌面与浏览器操作体验。
- 支持使用当前浏览器完成操作，完善连接状态提示与断线后的恢复体验。
- 支持通过自然语言查找可用工具和 Skills，减少反复查找与配置。
- 外部 MCP 服务支持按需连接、单独暂停和恢复，使用更灵活。
- 完善第三方服务的认证配置、连接测试与失败提示。

## 修正与改进

- 优化服务断开后的恢复提示和运行状态显示。
- 改善配置编辑与保存体验，保留未保存的草稿。
- 清理过时说明，统一功能介绍和更新文案。

## 升级提示

- 更新前请保存工作并停止 Runtime。
- 安装后重新启动应用与 Runtime；必要时在 MCP 客户端刷新工具列表或重新连接。
- 已有配置和权限设置继续保留；如系统再次提示权限，请按实际安装的应用完成授权。
