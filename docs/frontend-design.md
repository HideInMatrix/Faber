# Faber 前端视觉系统

按 `wondelai/skills/refactoring-ui`（本机安装版本 1.5.1）重构，不迁移 Vue / UnoCSS，不增加字体、图片或运行时依赖。当前以用户提供的蓝白设计系统展示图为参考，已提供 Runtime 页预览，并进一步重构插件、日志与关于页面的分组布局；此前的暖白、绿色方案不再作为设计方向。

## 设计约束

- 先用灰阶确认层级，再使用蓝色作为主操作色；状态同时保留文字，不只依赖颜色。
- 深海军蓝侧栏、冷白背景、白色卡片与柔和分层阴影。主操作使用 `#2563eb`，保证白色按钮文字的对比度；不将参考图的摄影灯光、透视、道具搬进操作界面。
- 4px 基础节奏，分组主要采用 8 / 16 / 24 / 32px；标签 12px、表单值 14px。页面标题统一 24px，主要分组标题 14px，避免所有文字都抢占层级。字体栈优先 Inter，再回退系统字体；未宣称已内置 Inter 字体文件。
- 主布局限定宽度；连接与启停区置顶并跨越两栏，基础配置与网络连接在左，访问控制在右。连接地址独占整行，不与启停按钮挤占宽度。1060px 以下按连接、基础、网络、访问控制排列，760px 以下表单单列，启停按钮移到地址下方。使用命名网格区域，保留真实的 aside 地标，不用 `display: contents` 展平语义容器。
- 页面不展示虚构统计或附加营销描述。MCP 复制入口收为带可访问名称的图标；启动前禁用。协议帮助与权限模式说明仍保留，不隐藏安全相关行为。
- 主操作实心、次操作描边；审批弹窗将更有限的“仅允许本次”作为主操作，三种决定的后端语义不变。

## 页面与行为

- Runtime：基础配置 / 网络连接 / 访问控制三组；只有实际启动后才显示 MCP 地址，草稿、密钥清除和启停禁用条件保留。名称、监听地址与端口同排，工作目录占整行；网络方案与协议相邻，其他方案仍按原字段定义展示。
- 长连接地址使用 14px 等宽字体，跨栏显示、自动换行、按内容撑高，不使用省略号或行数裁切。复制按钮固定在地址框右上角，并预留文字空间；点击复制传递原始字符串，不在字符串中插入换行或软分隔符。
- 插件：宽窗口下分为内置工具 / Computer Use、MCP / Skills 两排卡片；1150px 以下单列。浏览器配置、Skill 文档及工具目录使用原生可键盘操作的折叠区，常用启停、添加与权限检查始终可见。MCP / Skill 编辑时变为全宽，不重挂组件，刷新不丢草稿；不增加隐式保存、浏览器启动或权限请求。
- 日志：移除重复标题与说明，输出区填充可用视口，使用 14px 等宽字体；保留可选择且转义的原始文本、空状态、计数和清除按钮，不伪造级别或更改轮询逻辑。
- 关于：品牌版本独立小卡，更新状态与下载前缀各自分组；前缀输入与保存按钮相邻。窄窗口下品牌改为横向紧凑布局。保留签名验证、停止服务前的更新说明、进度、错误重试与重启入口；未改变真实更新控制器。
- 可访问性：活动导航 `aria-current`、跳转主内容、键盘焦点、减少动效；审批打开时背景 inert，并使用 Reka FocusScope 约束焦点，必须明确选择审批决定。

## Runtime 状态色

| 状态 | 颜色 | 说明 |
| --- | --- | --- |
| 加载中、启动中 | 蓝色 | 使用主色及低饱和底色，不再误报“已停止” |
| 正常运行 | 绿色 | 沿用原有成功色 |
| 停止中、公网异常 | 琥珀色 | 公网异常不代表本地 Runtime 已停止 |
| 加载失败、运行异常 | 红色 | 使用错误色，保留原始错误文本 |
| 已停止 | 灰色 | 正常空闲，不当成故障 |

状态文字和颜色同时变化。生命周期过渡优先于旧诊断，避免重试启动时仍显示旧错误、停止中仍显示正常绿色。颜色适配深浅主题，诊断提示同步采用对应浅底色；仅修改前端展示，不改变启动、停止或网络健康判断。减少动效时使用零时长过渡，避免给原本无过渡的状态徽标引入颜色插值。

## 验证与边界

- `npm run check` 包含 `verify:ui` 的八项回归（其中状态映射覆盖 11 种组合），并保留原有品牌、中英文、浏览器配置、Skills、发布来源和网络健康检查。
- `npm run verify:source-boundary`、`npm run verify:privacy` 与前端产物的分发检查。
- 隔离的 headless Chrome 预览覆盖四个路由、深浅色、中英文保留草稿、保存端口、启停锁定、日志清除、侧栏折叠、960 / 390px 布局以及审批 Tab / Shift+Tab 焦点和显式拒绝。追加真实网络字段定义下的五种方案切换、协议帮助展开、密钥显示/隐藏、网络/OAuth 密钥清除与撤销、运行后复制入口可用性检查。
- 测试仅使用模拟 API 和虚构工作目录，不读取真实配置，不启动 Runtime / Tunnel，不执行真实电脑动作。桌面版关于页通过独立组件 fixture 检查原生分支布局，不执行安装更新。
- 主要文字组合的实测对比度（sRGB）满足 4.5:1：浅色标签 6.29、正文 16.04、主按钮 5.17；深色标签 7.07、正文 14.80、主按钮 8.76。此结果不等于所有控件边界、异常状态与原生环境均已通过可访问性认证。
- 状态专项模拟预览覆盖深浅主题下的实际启动、运行、公网异常、恢复、停止中、异常退出与空闲状态；核对徽标确实使用对应语义色，徽标及告警文本对比度均达到 4.5:1。过程只拦截模拟 API，不启停真实 Runtime；报告为 `.local/ui-redesign/status-report.json`。
- 长地址专项覆盖 80 / 180 / 2048 字符、1180 / 960 / 390px 宽度及深浅主题，共 18 个组合：无省略、无裁切、无横向溢出，复制按钮不覆盖正文，传递的复制内容与原地址完全一致。使用模拟剪贴板，不读取或写入系统剪贴板；报告为 `.local/ui-redesign/long-url-report.json`。
- 三页布局专项覆盖深浅色与窄窗口、MCP/Skill/浏览器草稿刷新后保留、日志清空，以及关于页检查/保存/安装/重启的显式事件和安装后禁用状态；关键插件说明、日志正文和更新状态颜色实测对比度达到 4.5:1。关于页为真实组件的纯展示 fixture，不连接更新服务或执行安装；报告为 `.local/ui-redesign/secondary-layout-report.json`。
- 截图和模拟测试报告保存在忽略目录 `.local/ui-redesign/`，不进入发布产物。原生 WebView、VoiceOver 与真实更新安装尚需相应环境验收，不能由浏览器 fixture 代替。

## 当前视觉复核

按技能八项快速诊断，层级、灰阶可读性、留白、标签层次、间距体系、文本宽度和阴影七项通过。颜色对比这一项尚需补齐全部控件与异常状态的复验，因此内部检查暂记 **7/8（折算 9/10）**。这是检查表完成度，不是审美、参考图还原度或用户满意度；视觉效果必须以用户确认实际截图为准。原生 WebView 与 VoiceOver 仍待实机验收，当前未提交或发布。
