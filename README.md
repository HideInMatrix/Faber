# Faber

[English](README.en.md) · 简体中文

Faber，取自拉丁文“工匠”。让 AI 不止于对话，而是完成实际工作。

## 用途

让网页 AI 通过 MCP 调用本地工具：**网页 AI 负责思考，Pi Agent 负责本地执行。** 本软件不运行本地模型。

- **文件与命令**：读写工作目录内的文件，按权限策略执行 Shell 命令。
- **能力扩展**：添加 MCP 服务和 Skills，接入 Pi 插件体系。
- **公网连接**：通过 Cloudflare Tunnel 等网络方案连接网页 MCP 客户端，并提供 OAuth 认证和工具审批。

打开软件只加载配置；点击「启动」后才运行 MCP 和隧道。

## 功能特色

- **网页 AI，本地执行**：通过 MCP 将网页 AI 的推理能力与本地文件、命令和工具连接起来，无需部署本地模型。
- **Computer Use 电脑控制**：内置桌面与浏览器操作能力，在启用功能并授予所需系统权限后，让 AI 操作电脑。
- **灵活扩展能力**：管理 MCP 服务、Skills 和 Pi 插件，为不同任务组合所需工具。
- **多种连接方案**：支持 Cloudflare Tunnel、ngrok、FRP 和 Tailscale Funnel，通过 OAuth 授权连接兼容的网页 MCP 客户端。
- **操作权限可控**：按需选择逐次审批、自动批准文件修改或完全访问模式；启动、停止由用户控制，并可查看运行状态和日志。
- **开箱即用，双语界面**：提供 macOS 与 Windows 安装包，内置运行依赖；支持中英文切换、自动检查更新和手动确认安装。

## 安装

前往 [GitHub Releases](https://github.com/HideInMatrix/Faber/releases/latest)，下载适合自己电脑的**安装包**：

| 平台 | 下载与安装 |
| --- | --- |
| macOS · Apple Silicon（M 系列） | 下载 `aarch64.dmg`，打开后将应用拖入「应用程序」 |
| macOS · Intel | 下载 `x64.dmg`，打开后将应用拖入「应用程序」 |
| Windows · x64 | 下载 `*-setup.exe` 或 `.msi`，运行安装程序 |

无需另装 Node.js、Rust 或 Python；Cloudflare 客户端已内置。Linux 桌面版暂不支持。

首次使用：

1. 打开应用，配置工作目录、OAuth 密码和网络方案，保存后点击「启动」。
2. 将显示的 MCP 地址添加到支持 CIMD OAuth 的网页 MCP 客户端，完成授权。

macOS 安装包使用长期自签名证书，未经过 Apple 公证；Windows 安装包未进行 Authenticode 签名。若系统阻止打开，请先确认下载来源，再按系统提示允许运行。

应用会自动检查更新，确认安装在「关于」页面操作。`.app.tar.gz`、`latest.json` 和校验文件用于更新或校验，不是首次安装入口。

## Computer Use

让 AI 不只读写文件，还能通过内置 Computer Use 操作桌面与浏览器。

1. 停止 Runtime，在「插件」页面启用 **Computer Use**。
2. macOS 用户点击「设置权限」，按提示授予辅助功能和屏幕录制权限，再点击「重新检测」确认状态；Windows 用户需在可交互的桌面会话中使用。
3. 如需浏览器通道，展开「浏览器连接」，选择托管独立窗口（已安装的 Chrome / Edge，或另行准备的 Playwright Chromium），填写独立会话名和允许的网站；也可继续选择 CDP 附加模式。托管模式使用应用私有目录保存独立登录态，不读取日常浏览器资料；首次明确选择浏览器通道并经审批后才启动，保存或启动 Runtime 不会打开浏览器。
4. 启动 Runtime 后，通过已授权的 MCP 客户端调用相关工具；控制动作受当前权限审批策略约束。

启用 Computer Use 不会自动启动 Runtime 或隧道。修改开关或浏览器配置前，需要先停止 Runtime。

## Skills 导入

停止 Runtime，在「插件 → Skills → 添加 Skill」选择本地目录或 `SKILL.md`，点击「扫描目录」，勾选后批量添加。每份文档会生成独立配置：ID 默认取文件夹名，Skill 名称保留文档中的 `name`，每项可单独启停或移除引用。无需为根目录手填一个统一的来源 ID。

重复文件（含已停用配置）会跳过，同名 Skill 冲突会在预览中标出；兼容性警告不会阻止其他文档导入。已有的整目录来源可以点击「拆分目录」，预览并确认后替换为所选的独立配置；取消不会改变原配置。导入只保存文件引用，不复制、删除或执行原文件，也不会自动加载未配置的全局目录。

## 界面语言

默认使用中文。在侧边栏菜单下方的「界面语言」下拉框中选择 `English`，即可切换英文界面；选择会在本机记住。切换语言不会启动、停止 Runtime，也不会修改工作目录、密钥或权限设置。

语言切换仅影响界面文案；日志输出、第三方返回内容和用户填写的数据保留原文。

### 网络与启动排障

Faber 不再提供应用内 HTTP 代理、代理探活或授权连接测试设置。隧道、授权元数据和公网探活均使用各自的默认网络路径；实际出口由系统路由及用户的代理软件规则决定。仅打开系统 HTTP 代理不保证 cloudflared 或 Node.js 请求会进入代理；开启 TUN 时需在代理软件中配置相应分流与 DNS 规则。

启动失败提示会显示失败阶段。Cloudflare 建连失败时，可区分凭据认证、Fake-IP、DNS、证书验证、TLS 握手与连通性异常；HTTP/2 使用 TCP 7844，QUIC 使用 UDP 7844。请按日志检查所选协议和对应出口路径，不应只因单条 TCP/UDP 预检查失败就判断两种协议都不可用。

“隧道已连接，但公网服务验证失败”表示已进入后续验证阶段，需检查公网域名、源站转发地址与端口、访问策略或是否存在旧服务实例。详细原因保留在运行日志中。单次探活期限仍为 10 秒，运行中检查周期仍为 30 秒。

旧配置中的 `outbound_proxy`、`health_route` 及对应环境变量不再生效；下次保存时清除旧字段。External URL 方案仍已移除，旧配置加载为尚未启动的 Cloudflare 快速隧道草稿，清空原公网 URL 与方案专属参数；保存前不改写原配置文件。公网隧道仍需 OAuth 密码或静态令牌。

### 开发目录

- `scripts/`：构建、打包、发布及发行校验工具。
- `diagnostics/`：手动排障工具与排查说明。
- `tests/`：自动化测试，仅在本地保存，已被 Git 忽略；测试结果及取证数据也不提交。

`npm run check` 执行类型检查、前端构建和分发边界校验，不依赖本地测试文件。保有本地测试目录的开发机可运行 `npm run test:local`；该命令先构建服务再执行本地测试，新克隆的仓库不附带测试目录。CI 保留构建、发行来源、签名、分发边界与漏洞审计，不执行仅本地保存的测试。

根目录与 `apps/daemon` 同步固定 Computer Use 的版本，以保证 npm 对 workspace 依赖应用 Zod 安全覆盖规则。升级该包时需同步两处版本；发行边界校验会检查它们是否一致。
