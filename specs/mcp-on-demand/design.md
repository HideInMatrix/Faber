# 实现设计

- 配置 startup=on_start/on_demand 和可选 description。解析缺省兼容旧 on_start，新建表单默认 on_demand。
- McpSession 分离可恢复 pause 与永久 close；每轮连接独立取消信号和代次，防止暂停/停止后的迟到回调重新注册工具。
- 所有启用服务仍预注册 Pi 扩展及空工具槽，按需激活复用已有动态工具刷新边界，无需重建整个宿主。
- Runtime 管理本轮用户暂停集合。AI 的 mcp_connect 不能恢复用户暂停，界面显式恢复可以；全局停止取消全部连接。
- 本机目录缓存以连接身份哈希绑定，限制体积、白名单字段和原子保存；缓存错误仅影响离线目录，不拖垮连接。
- mcp_call 通过固定服务 ID 与原始工具名解析到实时注册表，在 MCP 适配层按真实目标进行审批与执行，并再次检查定义身份，兼容客户端未刷新新工具定义的情况。
- 搜索只读；启动、暂停、统一调用均维持现有操作审批。目录状态和服务器 instructions 给出准确下一步。
