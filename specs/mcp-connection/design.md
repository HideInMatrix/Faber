# 接入设计

用户已确认实施 requirements.md。

- 保持现有简洁表单、颜色和字体。添加服务时优先显示名称、传输、地址、认证；本地参数及 Header/环境变量采用可增删行。高级 JSON 和 OAuth 客户端信息折叠展示。
- 配置保存认证类型、Header 名称和凭据引用；实际密钥继续由本机 McpAuthStore 管理。本地编辑接口提供已保存值，公共快照继续只提供配置状态。
- HTTP 和 SSE 共用凭据组装与诊断；stdio 共用环境变量引用。测试采用临时凭据覆盖，不写配置或启动 Runtime。
- OAuth 基于已安装 SDK，顺序为预注册客户端、可用 CIMD、DCR。配置身份与发行者均绑定；支持自动分配本机回调端口或固定回调，PKCE、state、取消恢复及刷新继续有效。
- 新增单服务保存操作，将配置与凭据作为一个用户操作，失败恢复原凭据；只有全部成功才反馈保存成功。
- Runtime 明文显示已有值，移除显隐开关。浏览器页面通过受现有 Host/Origin 限制的本机配置接口读取值，不进入公开 MCP 端点。
- 通过隔离 SDK 服务、授权服务器和浏览器夹具验证；测试及截图只保存在本地。
