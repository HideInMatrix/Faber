# 实现设计

- Daemon 专用 capabilities 模块提供目录类型、本地检索和只读 BodyPlugin；Runtime 通过快照回调提供已配置 MCP、实时注册工具和当前允许模型调用的 Skill。
- 搜索入口在基础注册表与 Pi Runtime 中常驻。使用实时工具注册表判断可调用性；按需连接策略见相邻 mcp-on-demand 设计。
- MCP ID 为 mcp:<配置ID>，Skill ID 为 skill:<编码后的名称>；Skill 结果另外携带准确的 skills_read 参数。MCP 工具保持原名和所属服务关联。
- 搜索使用名称、描述、工具用途的加权匹配、Unicode 分词和少量中英文领域别名；去除请求套话，避免只凭“获取/查看”等动词命中所有服务。没有证据的结果不强行推荐。
- 同一连接配置发现过的工具名称和描述供离线时搜索；mcp-on-demand 扩展为白名单持久缓存，并增加首次用途说明。结果显式区分实时、缓存及仅配置元数据。没有读取过的服务不编造用途或工具。
- 返回 revision、checked_at、total、has_more、next_cursor，限制每页结果和每个服务的工具摘要。修订号覆盖身份、说明、状态和当前工具定义的变化，不包含查询时间。
- 服务器初始化说明与未知工具错误提供重新发现提示。capabilities_search 作为已注册的只读元数据工具不弹操作审批；其余工具仍走原审批。
- 以纯检索、真实 Pi/SDK 内存传输和隔离 Runtime 快照验证；不启动真实 MCP、隧道或调用业务工具。
