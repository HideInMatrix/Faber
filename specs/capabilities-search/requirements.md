# 统一能力搜索

用户已确认统一为 capabilities_search，并使用自然语言搜索；内部 ID 用于精确标识命中对象。本轮实现发现层，不修改服务启动策略或提交发布。

- R1：当 AI 用中文或英文描述任务时，默认同时检索已配置 MCP 和当前加载且允许模型调用的 Skill；空查询可浏览目录，可按类型筛选并限制数量；分页游标绑定查询和目录版本，过期时重新搜索。
- R2：结果提供稳定的类型化 ID、用途、当前状态、可用性、目录版本与检查时间。MCP 服务和 Skill 同名不混淆；工具原名不改变。
- R3：搜索读取实时注册表及连接状态。断线后历史工具描述仅用于匹配并标记为缓存，不提供已失效工具的调用指引；用户停用的服务不可调用。
- R4：Skill 命中包含现有 skills_read 的准确参数；MCP 命中仅指向当前实际注册的工具。未连接、未授权或禁用的服务明确提示在 Faber 处理，不虚构启动接口。
- R5：搜索不启动进程、不联网、不读取完整 Skill 正文、不执行工具。名称、描述与已发现的工具用途支持本地分词及中英文别名匹配，不引入模型或下载嵌入模型。
- R6：查询不索引或返回密钥、Header 值、环境变量、地址、启动参数和本地路径。disable-model-invocation 的 Skill 不进入模型搜索。
- R7：固定工具描述和服务器 instructions 引导 AI 首次使用前查询、Skill 先读取、目录失效时重新搜索；执行端继续校验当前工具，不以历史搜索授予权限。
- R8：保留原工具及 Skill 接口、审批和原名冲突规则。测试和记录仅保存在忽略目录。
